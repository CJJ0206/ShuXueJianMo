**脚本挡得住空值，挡不住糊弄。同一份复现命令出现在两条以上 issue 上即可疑。**

## 5. 环境三条坑

1. **PATH 上的 `python` 是 WindowsApps 空壳**，执行即报"未找到"。一律用
   `F:\anaconda\envs\ptg\python.exe`（bash：`/f/anaconda/envs/ptg/python.exe`）
2. **无 LaTeX / MATLAB / R / Word / LibreOffice** → 论文只能 Word/WPS；`.doc` 无法程序解析
3. **GitHub 不可靠**（今晚 push 连败三次）→ 三人同步**不得依赖远程仓库**：本地 git 管回滚，
   交接包打 zip 走网盘/局域网。装包只走 tuna 镜像。
   ⚠ **明天真实赛题的原文与附件禁止推入仓库**（`.gitignore` 已排除 `data/raw`）

补两条今晚实测的：
4. `subprocess` 在中文 Windows 默认按 GBK 解码子进程输出，**脚本打中文即崩**。
   自己写的任何捕获都要 `encoding="utf-8", errors="replace"`
5. **耗时估算必须先 warmup**：冷启动 19.3 ms vs 稳态 2.83 ms，差 6.8 倍。
   按冷启动估算力，会错误回避掉整个视频/DL 题型。计时须 `torch.cuda.synchronize()`
